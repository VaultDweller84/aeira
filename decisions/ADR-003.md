# ADR-003 — Mobile first, temas comutáveis, alto contraste

**Estado:** aceite · Set/2026 · **Reversibilidade:** alta

**Contexto.** O público chega quase todo por telemóvel e uma parte vê mal.

**Decisão.** CSS escrito para telemóvel como caso base; ecrã largo em
`@media (min-width:…)`. Barra de navegação fixa no fundo. Três temas
(`sereno` por defeito, `terra`, `contraste`), definidos só por variáveis CSS.
Tamanho de letra em três níveis.

**Justificação.** Um tema é só um conjunto de cores — separar isso do resto
permite acrescentar temas sem tocar em estrutura. O tema de alto contraste
não é um extra: é acessibilidade para o público-alvo.

**Consequências.** Todo o CSS novo tem de usar as variáveis de tema, nunca
cores literais. Alvos de toque ≥40 px.
