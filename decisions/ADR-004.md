# ADR-004 — Proxy próprio em vez de chave no cliente

**Estado:** aceite · Set/2026 · **Reversibilidade:** baixa (estrutural)

**Contexto.** O gerador de cartas precisa de um modelo de linguagem. O portal
é um ficheiro público: tudo o que estiver lá é visível.

**Opções.** (a) Chave da API no ficheiro. (b) API pública sem chave
(Pollinations e afins). (c) Cloudflare Worker próprio com a chave guardada.

**Decisão.** (c), com Gemini ou Groq à escolha por variável.

**Justificação.** (a) é roubo de quota garantido. (b) não tem garantia de
disponibilidade nem contrato de tratamento de dados — inaceitável num portal
comunitário que pede confiança. (c) é gratuito até 100 mil pedidos/dia.

**Consequências.** Uma peça de infraestrutura a manter. Em troca, ganhou-se o
sítio natural para pôr a agenda, as notícias e as sugestões — o Worker passou
de proxy a espinha dorsal.

**Nota de segurança.** O Worker **não é um proxy genérico**: recebe campos
com nomes fixos e escreve ele as instruções para o modelo. A chave não pode
ser usada para gerar outra coisa qualquer.
