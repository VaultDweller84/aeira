# ADR-014 — Alojamento no Cloudflare Pages

**Estado:** aceite · 1/9/2026 · **Reversibilidade:** alta

**Contexto.** O ADR-001 decidiu que o portal é um ficheiro HTML auto-alojado,
mas deixou por escolher onde. O requisito duro é **HTTPS**: sem ele não há
PWA nem cache offline, e a metade instalável do produto (ADR-010) não existe.
O `01-ARCHITECTURE.md` listava três candidatos com nível gratuito: GitHub
Pages, Netlify e Cloudflare Pages.

**Opções.** (a) GitHub Pages — o Hugo já tem conta GitHub, e o alojamento
viria com o repositório de graça. (b) Netlify — sem vantagem particular aqui.
(c) Cloudflare Pages.

**Decisão.** (c) Cloudflare Pages, na mesma conta do Worker.

- Site: projecto `aeira-portal` → **`https://aeira-portal.pages.dev`**
- Worker: `aeira` → **`https://aeira.hugompalmeida.workers.dev`**
- KV: `aeira-sugestoes`, ligado ao Worker com o nome `SUGESTOES`
- Publicação: **upload directo** dos ficheiros pelo painel, sem Git

**Justificação.** O ADR-004 já obriga a uma conta Cloudflare para o Worker e
para o KV. Alojar o site noutro sítio dava duas consolas, duas contas e dois
sítios onde procurar quando alguma coisa falha — para um projecto de
mantenedor único (R-01), isso é custo puro. O GitHub Pages só ganharia se o
repositório já existisse, e não existe.

**Sobre os nomes.** Pediu-se `aeira` para ambos e o Cloudflare recusou o
segundo: os nomes são únicos na conta e o Worker foi criado primeiro. A
alternativa oferecida era `aeira-77z.pages.dev`, impossível de ditar a
alguém ao telefone. Ficou `aeira-portal`. O endereço do Worker nunca é visto
por um munícipe; o do site é o que se diz em voz alta — daí a escolha ter
recaído sobre o que se lê.

**Consequências.**

1. **Publicar é um acto manual.** Cada versão nova obriga a arrastar os
   ficheiros para o painel, e a mudar a `VERSAO` no `sw.js` (R-08). Não há
   publicação automática enquanto não houver repositório.
2. **A variável `ORIGENS` do Worker tem de acompanhar o endereço do site.**
   São dois sítios a apontar um para o outro: o `CONFIG.API` no `index.html`
   aponta para o Worker, e o `ORIGENS` no Worker autoriza o site. Mudar um
   sem mudar o outro parte as cartas, a agenda e as sugestões em silêncio —
   as notícias continuam, o que torna a avaria difícil de notar.
3. **O `pages.dev` é endereço de trabalho, não de divulgação.** Não serve
   para dizer a ninguém na aldeia. Fica por decidir, em ADR próprio, o
   domínio `aeira.pt` — e com ele o primeiro custo recorrente do projecto,
   que contraria a restrição C-02 e agrava o R-01: um domínio por renovar
   mata o portal mesmo com o código intacto.
4. **O repositório Git continua por montar.** Hoje o código vive num único
   disco, o do Hugo. É a mitigação por fazer mais óbvia do R-01 e não fica
   resolvida por este ADR.
